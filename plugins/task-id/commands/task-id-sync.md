argument-hint: "[--apply]"

이미 쓰고 있지만 원격 ref 가 없는 작업 번호를 찾아 등록한다. `/task-new` 는 원격 ref 를 번호 등록부로 보기 때문에, 플러그인을 쓰기 전에 만든 번호나 플러그인 없이 만든 번호가 등록돼 있지 않으면 그 번호를 다시 줄 수 있다.

보는 곳은 셋이다 — 원격의 **모든 브랜치**, 이 PC 의 **모든 로컬 브랜치**(푸시 전), 이 PC 의 **작업 트리와 형제 워크트리**(커밋 전).

## 순서

1. 사용자가 `--apply` 를 주지 않았으면 **조회만** 한다.

   ```
   node "${CLAUDE_PLUGIN_ROOT}/scripts/sync.js"
   ```

2. 결과 JSON 을 보고한다.
   - `numbers` — 찾은 번호 수, `alreadyRegistered` — 이미 등록된 수, `toRegister` — 등록할 수
   - `scanned` — 원격 브랜치·로컬 브랜치·워크트리를 몇 개 봤는지
   - `duplicates` — **같은 번호에 다른 문서가 있는 경우.** 등록과 상관없이 그대로 알린다. 고치지 않는다(번호를 바꿀지는 사람이 정한다).

3. `toRegister` 가 0 이 아니고 사용자가 아직 `--apply` 를 주지 않았다면, 무엇을 등록하는지 보여 주고 **승인을 받은 뒤** `--apply` 로 다시 부른다. 원격에 ref 를 만드는 일이다.

4. `--apply` 결과의 `registered` 를 보고한다. `rejected` 가 있으면 그 사이 다른 세션이 같은 번호를 `/task-new` 로 받은 것이다.

## 언제 부르나

- 플러그인을 처음 붙일 때 한 번 (저장소에 하나)
- 팀원이 플러그인을 설치한 뒤 자기 PC 에서 한 번 — 아직 푸시하지 않은 브랜치와 커밋 전 문서의 번호가 등록된다
- 플러그인 없이 만든 번호가 생겼을 때
