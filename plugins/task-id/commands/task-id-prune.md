description: 쓸모를 다한 선점 ref 를 원격에서 정리한다 (기본은 조회만)
argument-hint: "[--apply] [--keep N] [--domain d] [--year y]"
---

선점 ref 를 정리한다. ref 는 발급 순간의 선착순 판정에만 쓰이고, 그 번호의 작업 기록 파일이 원격 기본 브랜치에 커밋되면 역할이 끝난다.

## 순서

1. 사용자가 `--apply` 를 명시하지 않았으면 **조회만** 한다.

   ```
   node "${CLAUDE_PLUGIN_ROOT}/scripts/prune.js" <인자>
   ```

2. 결과 JSON 을 읽고 보고한다.
   - `refs` — 원격에 있는 선점 ref 수
   - `deletable` — 지울 수 있는 수, `kept` — 남기는 수와 이유
   - `byDomain` — 도메인별로 커밋까지 끝난 최대 번호
   - `deleted` — 실제로 지운 수 (조회만 했으면 0)

3. `deletable` 이 0 이 아니고 사용자가 아직 `--apply` 를 주지 않았다면, **무엇을 지우게 되는지 먼저 보여주고 승인을 받는다.** 승인 없이 `--apply` 를 붙이지 않는다.

4. 원격 ref 삭제는 되돌릴 수 없다. 다만 지우는 대상은 파일이 이미 커밋된 번호뿐이라, 지워도 다음 발급 번호는 내려가지 않는다.

## 지우지 않는 것

- **작업 기록 파일이 아직 원격에 없는 번호** — 지우면 그 번호가 다시 풀린다. 다른 PC 에 푸시 안 된 초안이 있으면 같은 번호가 두 번 나간다.
- **최근 `--keep` 개(기본 20)** — 확인된 조건 외에 두는 여유분.
